1# Git and GitHub
2 
3A reusable provider-neutral Git vocabulary and GitHub hosting vocabulary,
4loaded as bundled Forma libraries. These are declarations in the existing
5ontology language, not a new language or live provider integration.
6 
7## Read and run
8 
9- Language: [ontology.lisp](../../preludes/ontology.lisp).
10- Libraries: [std/git.lisp](../../libraries/std/git.lisp) and [github.lisp](../../libraries/github.lisp).
11- Model: [model.lisp](model.lisp).
12- Operations: [scenario.ts](scenario.ts) and [run.ts](run.ts).
13- Vocabulary and extension conventions: [Git libraries guide](../../docs/git-libraries.md).
14- Run: `pnpm example:github`.
15- Check: `pnpm model:check examples/github/model.lisp`.
16- Coverage: [forma-libraries.test.ts](../../test/forma-libraries.test.ts).
17 
18The scenario models synthetic forks, dependencies, merge parents, a cross-fork
19pull request and issue references. It runs on local in-memory Triplex, with no
20GitHub API synchronization, configuration deployment or permission enforcement.
Experimental v0.1 · Local in-memory runtime. All explorations
