1# Support desk
2 
3A Forma-only model exercises object creation, clear-then-set updates, references,
4relations, negation, ordering and grouped aggregates. It uses the bundled
5ontology language; there is no separate support-desk prelude.
6 
7## Read and run
8 
9- Language: [ontology.lisp](../../preludes/ontology.lisp), with [construction hooks](../../preludes/ontology-compiler.lisp).
10- Model: [model.lisp](model.lisp).
11- Operations: [run.ts](run.ts).
12- Run: `pnpm example:support-desk`.
13- Check: `pnpm model:check examples/support-desk/model.lisp`.
14- Coverage and checked output: [agent-guide.test.ts](../../test/agent-guide.test.ts) and [agent guide](../../apps/site/public/llms-full.txt).
15 
16The run opens three synthetic tickets, escalates one, closes another and prints
17three Datalog query results from local in-memory Triplex. There is no durable
18server, product authorization or external help-desk integration.
Experimental v0.1 · Local in-memory runtime. All explorations
