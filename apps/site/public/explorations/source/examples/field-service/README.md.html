1# Field service
2 
3The same work-order model is authored in TypeScript and Forma. A test compares
4their portable `OntologyIR`. The language is the package's bundled ontology
5prelude; there is no separate field-service language prelude.
6 
7## Read and run
8 
9- Language: [ontology.lisp](../../preludes/ontology.lisp), with [construction hooks](../../preludes/ontology-compiler.lisp).
10- Model: [model.lisp](model.lisp) or [model.ts](model.ts).
11- Operations: [run.ts](run.ts).
12- Run: `pnpm example`.
13- Check: `pnpm model:check examples/field-service/model.lisp`.
14- Coverage: [field-service.test.ts](../../test/field-service.test.ts).
15 
16The run seeds a technician and work order, invokes `assign-work-order` and
17prints `assigned-work` from local in-memory Triplex. Facts and actor ids are
18synthetic; this does not provide persistence, a server or authorization.
Experimental v0.1 · Local in-memory runtime. All explorations
