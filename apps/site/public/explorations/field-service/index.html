02Documentation

Field service

The same work-order model is authored in TypeScript and Forma. A test compares their portable OntologyIR. The language is the package's bundled ontology prelude; there is no separate field-service language prelude.

Read and run

  • Language: ontology.lisp, with construction hooks.
  • Model: model.lisp or model.ts.
  • Operations: run.ts.
  • Run: pnpm example.
  • Check: pnpm model:check examples/field-service/model.lisp.
  • Coverage: field-service.test.ts.

The run seeds a technician and work order, invokes assign-work-order and prints assigned-work from local in-memory Triplex. Facts and actor ids are synthetic; this does not provide persistence, a server or authorization.

03Executable notebook

Run it, then read what it did.

Run in a clone with Node 24 and pnpm 10.11.0. Each run starts a fresh in-memory Triplex host. This static page does not run code in your browser; the output below is regenerated by running the example during site checks.

examples/field-service/model.lispmodel
(define-entity Technician
  (:field [technician/name String {:required true}]))

(define-entity WorkOrder
  (:field [work-order/title String {:required true}])
  (:field [work-order/status String {:required true}]))

(define-relation assigned-to WorkOrder Technician
  (:field [assigned-to/assigned-at Instant {:required true}]))

(define-action assign-work-order
  (:input [workOrder String {:required true}])
  (:input [technician String {:required true}])
  (:returns String)
  (:do (changes
    (clear workOrder :work-order/status)
    (set workOrder :work-order/status "assigned")
    (link assigned-to workOrder technician {:assigned-to/assigned-at now}))))

(define-datalog-query assigned-work
  (:query
    {:find ["?title" "?technician"]
     :where
       [["?work" ":work-order/title" "?title"]
        ["?work" ":work-order/status" "?status"]
        ["!=" "?status" "cancelled"]
        ["not" ["?work" ":work-order/status" "archived"]]
        ["?assignment" ":assigned-to/from" "?work"]
        ["?assignment" ":assigned-to/to" "?person"]
        ["?assignment" ":assigned-to/assigned-at" "?assignedAt"]
        ["?person" ":technician/name" "?technician"]]}))
