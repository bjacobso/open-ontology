Git and GitHub

A reusable provider-neutral Git vocabulary and GitHub hosting vocabulary, loaded as bundled Forma libraries. These are declarations in the existing ontology language, not a new language or live provider integration.

Read and run

  • Language: ontology.lisp.
  • Libraries: std/git.lisp and github.lisp.
  • Model: model.lisp.
  • Operations: scenario.ts and run.ts.
  • Vocabulary and extension conventions: Git libraries guide.
  • Run: pnpm example:github.
  • Check: pnpm model:check examples/github/model.lisp.
  • Coverage: forma-libraries.test.ts.

The scenario models synthetic forks, dependencies, merge parents, a cross-fork pull request and issue references. It runs on local in-memory Triplex, with no GitHub API synchronization, configuration deployment or permission enforcement.

Executable notebook

Run the example

Run in a clone with Node 24 and pnpm 10.11.0. Each run starts a fresh in-memory Triplex host.

pnpm install --frozen-lockfile
pnpm example:github

The model

Full model with line links · Raw

(import "/github")

; Join the hosting layer to the shared Git graph, including cross-fork PRs.
(define-datalog-query github-open-pull-requests
  (:query
    {:find ["?repository" "?number" "?author" "?base" "?headRepository" "?head"]
     :where [["?pr" ":github-pull-request/state" "open"]
             ["?pr" ":github-pull-request/repository" "?hosting"]
             ["?hosting" ":github-repository/full-name" "?repository"]
             ["?pr" ":github-pull-request/number" "?number"]
             ["?pr" ":github-pull-request/author" "?account"]
             ["?account" ":github-account/login" "?author"]
             ["?pr" ":github-pull-request/base" "?baseBranch"]
             ["?baseBranch" ":git-branch/name" "?base"]
             ["?pr" ":github-pull-request/head" "?headBranch"]
             ["?headBranch" ":git-branch/name" "?head"]
             ["?headBranch" ":git-branch/repository" "?headRepo"]
             ["?headHosting" ":github-repository/repository" "?headRepo"]
             ["?headHosting" ":github-repository/full-name" "?headRepository"]]}))
