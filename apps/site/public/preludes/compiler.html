The pitch

A source to learn from.

Read this when tracing how Forma recognizes a form, how its slots are described, or which compile-time hook it calls. Most model authors can start with the ontology guide instead.

What’s included

Descriptors
define-form describes heads, identifiers, slots, and result types.
Meta hooks
meta-fn declares compile-time bindings, validation, construction, and result-type functions.
Bootstrap
src/forma.ts supplies this source first to bootstrapFromSources, alongside the ontology and elaboration sources.

Inside the compiler

How meta-fn itself is described

Compiler source excerpt, copied from compiler.lisp. It describes a compile-time form; it is not a runnable ontology model or a bundled import.

To trace this source, follow the bootstrap in src/forma.ts. Read the form descriptor, locate its named hook, then inspect the adapter’s supported payload conversion.

Current availability

Shipped · compiler support

Shipped compiler infrastructure, not an installable platform prelude. Do not use (import "/compiler") or paste define-form into a model: the bundled import registry and Triplex adapter do not expose a language-extension workflow.

Work in a clone; the package is not released on npm. Native platform deployment, synchronization, and the oo package manager are not available.
