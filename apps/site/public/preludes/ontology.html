The pitch

A vocabulary to build on.

Start here for a support desk, a field-service operation, or a domain that does not have a bundled vocabulary yet. Extend Git or GitHub using these same forms.

What’s included

Object and link types
define-entity and define-relation, with fields and typed references
Writes
define-action and define-mutation, using create, set, clear, link, and changes
Reads
define-datalog-query, with joins, negation, aggregates, and ordering
Authoring paths
Forma and the TypeScript DSL produce the same JSON-safe OntologyIR

Authoring example

A task model with replaceable state

This complete model declares tasks, two actions, and a named query. complete-task clears the old boolean before setting the new one, so completed tasks leave the open-tasks result.

Save the complete model as examples/my-domain/model.lisp inside a repository clone, then check it: 

pnpm install --frozen-lockfile
pnpm model:check examples/my-domain/model.lisp

Use Node 24 and pnpm 10.11.0. Imports expand to ordinary declarations and share one namespace; imported types cannot be redefined. Only /std/git and /github are bundled import paths.

Run a checked-in scenario

The checked-in support-desk scenario demonstrates a larger model with references, relations, state changes, and queries. The field-service example compares Forma and TypeScript IR. 

pnpm example:support-desk

Current availability

Available · experimental v0.1

Experimental v0.1: one package and a local in-memory runtime. No durable host, HTTP server, or product authorization. The source describes more forms than the Triplex adapter supports; use the five declarations documented here. HTTP, view, and other recognized forms are not runnable model features.

Work in a clone; the package is not released on npm. Native platform deployment, synchronization, and the oo package manager are not available.
