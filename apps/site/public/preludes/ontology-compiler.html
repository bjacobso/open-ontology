The pitch

A source to learn from.

Read this when debugging a recognized form or following a field from its declaration to the payload consumed by the TypeScript adapter. Start with the hook named in ontology.lisp.

What’s included

Hook contracts
Each meta-fn declares a kind, input, output, and executable body.
Construction
entity/construct reads entity names and child fields and builds an Entity payload. The TypeScript adapter converts supported payloads to OntologyIR.
Scope
The file also contains hooks for forms outside the current Triplex adapter, including HTTP declarations. Their presence does not make those forms supported model features.

Inside the compiler

The entity construction hook

Compiler source excerpt, copied from ontology-compiler.lisp. meta/* and construct/* calls are compiler-hosted operations. This is not a runnable model example.

To trace this source, follow the bootstrap in src/forma.ts. Read the form descriptor, locate its named hook, then inspect the adapter’s supported payload conversion.

Current availability

Shipped · compiler support

These hooks run as compiler infrastructure. They are not domain actions, and this file is not a bundled import. The adapter accepts only its supported declaration set, regardless of which other hooks are present.

Work in a clone; the package is not released on npm. Native platform deployment, synchronization, and the oo package manager are not available.
