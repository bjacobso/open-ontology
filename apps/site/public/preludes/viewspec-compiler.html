The pitch

A source to learn from.

Read this to understand how a view hook gathers state, query names, input names, and definitions before invoking descriptor-tree validation. It is a reference for compiler contributors.

What’s included

Validation hook
view/validate is a validate-kind meta-fn returning DiagnosticList.
Context
The hook collects layout, state, main and named queries, input parameters, and local definitions.
Hosted dependency
meta/validate-descriptor-tree delegates layout checking to the hosted ViewSpec descriptor catalog.

Inside the compiler

The hosted layout-validation hook

Compiler source excerpt, copied from viewspec-compiler.lisp. This shows validation machinery; it is not a runnable view or ontology model.

To trace this source, follow the bootstrap in src/forma.ts. Read the form descriptor, locate its named hook, then inspect the adapter’s supported payload conversion.

Current availability

Shipped · compiler support

The source ships and is loaded at bootstrap, but the Triplex ontology adapter rejects view declarations. This package does not render layouts, provide a UI server, or expose a ViewSpec domain import.

Work in a clone; the package is not released on npm. Native platform deployment, synchronization, and the oo package manager are not available.
